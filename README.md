# Wine Quality Prediction Using Machine Learning and Neural Networks

## Project Overview
This project investigates the relationship between physicochemical properties and wine quality using unsupervised learning, supervised learning, and neural networks.

## Dataset
- Red wine: 1,599 samples
- White wine: 4,898 samples
- Total: 6,497 samples
- Chemical features: 11

## Methods
- K-Means Clustering
- Decision Tree Classification
- K-Nearest Neighbors (KNN)
- Multilayer Perceptron (MLP)

## Results

| Model | Accuracy | Macro F1 |
|---|---:|---:|
| Decision Tree | 54.92% | 0.283 |
| KNN | 56.31% | 0.270 |
| MLP | 56.46% | 0.251 |

The neural network achieved the highest overall accuracy, while the Decision Tree achieved the highest macro F1 score.
